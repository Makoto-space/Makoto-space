これまで様々な病気に対する臨床検査薬を様々な統計解析手法を使って開発してきました。この探究を続ける中でデジタル技術（ビッグデータ解析、人工知能）を使えばより優れた早期診断ができて、早期治療により人々の健康寿命を延ばせるのではないかと考えるようになりました。そこでプログラミングスクールでpythonで統計解析全般、機械学習と深層学習を学びました。独自に開発した成果物として、StreamlitとFastAPIを用いて深層学習モデル（Densenet201, AutoEncoder, BERT）を活用した「スマホで撮った発疹画像と問診票を用いて皮膚疾患を診断するアプリ」を制作しました。コードはMakoto-space/github.ioに載せています。本WebアプリをDockerでコンテナ化し、Google Cloud Run上にデプロイしました(Webアプリの詳細はこちら→https://skin-check-488916091193.asia-northeast1.run.app)。
